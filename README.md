# stock-monitor

日本株の板・歩み値・価格トレンドを解析し、買い圧力／売り圧力を可視化するための実験プロジェクトです。

## 目標

- 板の厚さだけでなく、板が「食われた」「補充された」「取り消された」動きを判定する
- 歩み値と板変化を組み合わせて注文フローを推定する
- 移動平均などのトレンド情報と統合し、最終的に 0〜100 の圧力スコアを表示する
- 最終売買判断は人間が行う（初期版では自動売買しない）

## 開発方針

1. シミュレーションデータで判定ロジックを検証
2. 板・約定解析エンジンを実装
3. スコアリングを追加
4. リアルタイム市場データへ接続
5. iPhone から確認できるダッシュボードを追加
