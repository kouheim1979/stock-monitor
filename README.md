# stock-monitor

日本株の板・歩み値・価格トレンドを解析し、買い圧力／売り圧力を可視化するための実験プロジェクトです。

## 目標

- 板の厚さだけでなく、板が「食われた」「補充された」「取り消された」動きを判定する
- 歩み値と板変化を組み合わせて注文フローを推定する
- 移動平均などのトレンド情報と統合し、最終的に 0〜100 の圧力スコアを表示する
- 最終売買判断は人間が行う（初期版では自動売買しない）

## MVP で実装するもの

- 2時点の板スナップショット比較
- 歩み値から買い成行／売り成行の方向を推定
- 各価格帯の板について、約定で食われた量・補充量・取消量を推定
- 上位板の厚さから Order Book Imbalance を算出
- 約定フロー・板補充・板取消を合わせて 0〜100 の Pressure Score を算出
- pytest によるロジック検証

## 板補充の考え方

板数量を `Q`、その観測区間での約定数量を `E` とすると、価格帯ごとに次の保存則を使います。

```text
current = previous + additions - executions - cancellations
```

したがって、

```text
net_queue_flow = current - previous + executions
```

が正なら「ネットで補充」、負なら「ネットで取消」と判定します。

例：998円の買い板が 8,000株あり、2,000株売られたのに次の観測で7,800株残っていた場合、

```text
7,800 - 8,000 + 2,000 = +1,800
```

なので、観測区間中に少なくともネット1,800株の買い板補充があったと推定します。

## 実行例

```bash
python -m pip install -e ".[dev]"
python examples/demo.py
pytest -q
```

## 開発ロードマップ

1. シミュレーションデータで判定ロジックを検証
2. 板・約定解析エンジンを実装
3. スコアリングを追加
4. リアルタイム市場データへ接続
5. 移動平均・MACD等のトレンド判定を統合
6. iPhone から確認できるダッシュボードを追加

## 注意

現時点の補充・取消判定は、板スナップショットと約定数量からの推定です。取引所の注文ID単位の完全な再構成ではありません。また Pressure Score の重みは初期仮値で、将来的に実データで検証・校正します。
